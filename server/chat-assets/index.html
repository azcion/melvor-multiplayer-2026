Link a character

In Melvor, open Options → Browser Chat → Link browser. Enter the one-use code before its displayed expiry. Each character needs its own code.

Browser locks are unavailable. Close other Chat tabs before linking and keep only this tab open until linking finishes. If an identity disappears after simultaneous linking, obtain a fresh code and link it again here.

Expired or already used? Get a fresh code in Melvor. If linking is limited, wait before trying again. At capacity, revoke an unused browser in Melvor or remove an identity here. Codes are never retried automatically.
